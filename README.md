# Red Herring

**A red herring is a misleading clue. So is every scam.**

Red Herring is a Chrome extension that explains, in plain words, why an email,
sign-in page or download looks like a scam. Everything runs on your computer:
no account, no servers, no tracking.

- **[User guide](https://matthewidavis.github.io/RedHerring/)**: installing it, reading the notes, web and download warnings, settings and FAQ
- **[Privacy policy](https://matthewidavis.github.io/RedHerring/privacy.html)**: what it reads, what it keeps, and what never leaves your computer

Questions, a scam it missed, or a false alarm:
